🐘 Zookeeper — Kafka's brain, manages who's alive and which broker owns what
📨 Kafka — message queue, holds data between producer and Spark
🐍 Producer — Python script, fetches data from API and sends to Kafka
⚡ Spark — reads from Kafka, cleans data, writes to PostgreSQL
🗄️ PostgreSQL — two instances: one for your data, one for Airflow metadata
✈️ Airflow — scheduler, triggers Spark jobs on a schedule via DAGs
